# Write a SpecNotary spec

1. If `specnotary` is not installed, run:
   `pip install "git+https://github.com/OwenBell0930/specnotary.git"`
   Do not ask the product manager to make SpecNotary the current workspace.
2. Follow `skills/specnotary/SKILL.md` strictly.
3. Ask the product manager only: what raw material is still missing, whether the result is right, and where the review pack is.
4. Do not ask them to operate internal tools or edit internal files.
