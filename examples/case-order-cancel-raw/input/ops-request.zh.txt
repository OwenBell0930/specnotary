# 运营需求摘录（虚构电商 · 脱敏）
# Raw request: unpaid/paid but unshipped order cancel

背景：自营商城 App，日单量约 8 万。
诉求：买家在「未发货」前可自助取消订单；已发货走售后，不在本期。
痛点：客服每天处理大量「我点错了想取消」工单；库存被无效占用。
约束：
- 待支付订单取消后应关闭，并释放优惠券（若已锁定）。
- 已支付未发货取消后须自动退款原路返回，库存回库，时效目标：提交后 2 小时内退款状态可查。
- 商家仓配已接单（履约中）时买家不可自助取消，只能联系客服。
- 风控命中订单禁止自助取消。
非目标：部分取消、改地址、跨境税、订阅购。
